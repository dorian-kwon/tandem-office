# v0.14.2 출시 전 확인

대상 저장소는 `dorian-kwon/tandem-office`, 출발 커밋은 `eb8a2601f`다. AI 비교 작업은 별도 `compare-ai` 브랜치에 있으며 이 출시 범위에 포함하지 않는다. Windows만 배포한다.

## 확인한 동작

- `apps/docs/tests/translate-runs-roundtrip.test.ts`: 실제 열기·번역 도구·자동 저장 경로에서 새 이탤릭 구간이 `word/document.xml`의 `<w:i>`로 저장되는지 검사했다. 주변 일반 글에는 이탤릭이 없고 기존 굵게 속성은 유지됐다. 저장한 파일을 다시 파싱해 편집기에 넣었을 때도 같은 구간만 이탤릭이었다. Word 프로그램에서의 화면 확인은 하지 않았다.
- 같은 파일: 표 셀 번역 → 자동 저장 → 실행 취소 → 자동 저장 → 다시 실행 → 자동 저장을 검사했다. 매 저장 파일을 다시 읽어 내용이 해당 단계와 같은지 확인했다. 모든 표 구조를 검증한 것은 아니다.
- 폴더 감시 알림: 닫힌 워드 탭은 `webContents`를 남기고 렌더러만 해제할 수 있다. 기존 `isDestroyed()` 검사로는 이 수신자를 거르지 못한다. 기존 전송 루프를 분리한 재현 시험에서 `Render frame was disposed…` 또는 `Object has been destroyed` 예외가 다음 화면의 알림까지 막았다. 해당 두 종료 오류만 건너뛰도록 수정한 뒤 열린 화면의 수신과 다른 오류의 재전파를 확인했다. 실행 중 앱을 재시작하거나 실제 화면에서 재현하지는 않았다.

## 입력 크기 측정

실제 모델 호출 없이 현재 코드가 만드는 고정 지침과 도구 정의를 비교했다. 아래 값은 토큰 수나 응답 시간이 아니다. 문서·프로젝트 맥락과 다른 공용 도구가 붙기 전의 값이다.

| 항목                               | 일반 창 | 번역 출력 창 |
| ---------------------------------- | ------: | -----------: |
| 지침 글자 수                       |  25,100 |       15,885 |
| 도구 수                            |      42 |           28 |
| 도구 정의 JSON 글자 수             |  47,098 |       27,184 |
| 지침·도구 묶음 JSON의 UTF-8 바이트 |  72,906 |       43,444 |

고정 입력은 UTF-8 바이트 기준 약 40.4% 줄었다. 실제 첫 응답 및 전체 작업 시간의 개선율은 미측정이다. 이전 작업의 임시 성능 패치와 측정 기록은 현재 checkout에 없다. 실제 제공자 비교는 같은 문서·모델·작업으로 제공자 및 캐시 조건을 기록하며 별도로 측정해야 한다.

후속 요청의 추가 축소는 번역 출력 창에서만 적용한다. 완료된 이전 요청의 `read_runs`, `read_blocks`, `get_document_context` 결과가 4,000자를 넘으면 전송할 사본에 앞부분과 다시 읽으라는 표식을 넣는다. 원본 대화 기록, 현재 요청의 읽기 결과, 오류 결과, 사용자 지시, 도구 호출·인자, 스킬 안내는 그대로 둔다. 별도 AI 요약 요청은 추가하지 않는다. 테스트의 18,000자 읽기 결과는 후속 전송에서 약 4,100자 이하가 됐다. 일반 창에는 이 제한을 적용하지 않는다.

- 독립 코드 리뷰에서 Critical·Important 결함은 발견되지 않았다. 실제 Electron 화면·실제 AI 응답 시간·패키징은 리뷰 범위 밖이다.
- 실제 AI 구독 요청, 앱 빌드·실행·재시작, 릴리스 게시·푸시는 하지 않았다.

## 출시 전에 남은 것

`docs/releases/0.14.2.md`가 게시할 본문 초안이다. 버전은 아직 0.14.1이다. 약관 동의 확인, v0.14.2 번호와 최종 본문 확인 뒤 버전 두 곳을 올리고 커밋·푸시한다. 이어 정식 릴리스와 Windows build만 실행하고 설치 파일·blockmap·`latest.yml` 및 CI 결과를 확인한다. 현재 main의 기존 GitHub CI 실행 `42492620652`는 확인 시 진행 중이었다.

출시 스킬이 지정한 `humanize-korean`은 로컬에서 찾지 못했다. 저장소 내 `humanizer`의 사실 보존·군더더기 제거 기준으로 한국어 본문을 직접 윤문했다.
