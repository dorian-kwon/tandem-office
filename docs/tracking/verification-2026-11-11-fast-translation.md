## 동작 증거

- 긴 문단은 임의로 자르지 않고 큰 단위는 제외 수로 보고.
- 편집·분할·병합·삭제·중복·이동·새 문서와 외부 노트 변경에 대해 원문과 구조를 재검사.

- 작은 100문단과 2만 자 문맥을 처리한 뒤 재실행: 완료 글 재사용 100, 추가 번역 요청 0.
- 사용자 지시·스킬의 실수로 붙인 키/비밀번호는 기존 가림 규칙을 유지한다. 번역 대상 문서의 허용된 원문은 정확히 전달하고 강제 placeholder로 덮어쓰지 않는다.
