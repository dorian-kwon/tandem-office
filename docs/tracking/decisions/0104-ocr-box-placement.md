# 0104 docx 그림의 OCR 글은 AI가 준 박스로 그림 위에 불투명 텍스트 상자로 놓고, 번역은 상자 안 글도 읽는다

## 맥락

번역 프로젝트에서 docx·xlsx에 박힌 그림을 OCR하면, 읽은 글은 "그림 뒤 문단 / 문서 끝 / 표 칸 / 엑셀 칸 / 새 시트" 가운데 하나에 글만 놓였다. 그림 속 글이 있던 자리와 크기는 사라졌다. 사용자는 글자가 있는 부분마다 그림 위에 박스를 놓고, 글자 크기도 맞추고, 그 글을 번역에도 넣기를 원했다(설계 `docs/plans/ocr-box-placement.md`, 계획 `docs/plans/ocr-box-placement-implementation.md`).

## 결정

- **AI가 글과 자리와 글자 크기를 한 번에 준다.** docx 안의 그림(`boxable`)은 기존 페이지 읽기 요청 대신 박스 읽기 요청(`apps/shell/src/shared/ocr-boxes.ts`)으로 읽는다. 그림 한 장에 AI 호출 한 번이고, 보내는 이미지와 확인 화면의 요금 문구는 그대로다. 답은 `<boxes>` 안의 JSON이고 좌표와 글자 줄 높이는 그림의 천분율이다. 형식이 틀리면 한 번 다시 묻고, 또 틀리면 지금의 읽기 실패와 같다. 결정 0102의 "OCR은 AI로만"은 그대로다.
- **박스를 걸러내되 글은 남긴다.** 범위 밖 좌표는 그림 안으로 맞추고, 넓이가 없거나 그림의 85% 넘게 덮는 박스는 버린다. 박스가 버려져도 `payload.text`에 글이 남아 목록 배치로 돌아갈 수 있다.
- **사람이 고쳐 확정한다.** 배치 화면이 그림 위에 박스를 겹쳐 보이고, 사람이 옮기고 크기를 바꾸고 지우고 더하고 글을 고친다. 확정 전에는 문서에 쓰지 않는다.
- **불투명 흰 텍스트 상자로 쓴다.** 박스마다 `buildAnchoredTextboxParagraphXml`로 만든 떠 있는 텍스트 상자다. 그림 뒤 원문 픽셀 위에서도 번역문이 읽히게 불투명 흰색이며, 그림 파일은 바꾸지 않는다. 폰트 크기는 읽은 줄 높이를 문서에 놓인 그림 크기에 곱해 환산한다(`boxFontHalfPoints`).
- **상자를 놓을 수 있는 그림은 좁게 잡는다.** 본문 문단 안에서 혼자 있고 왼쪽 정렬이며 들여쓰기가 없고, 잘리거나 돌려지거나 떠 있지 않은 줄 안 그림만이다(`inspectBoxableImage`). 나머지는 지금의 목록 배치("그림 뒤 문단")를 쓰고 화면이 이유를 알린다.
- **번역이 상자 안 글을 읽는다.** 편집기의 번역(`read_runs`, `translate_blocks`)이 텍스트 상자의 문단을 `box`·`paragraph` 번호로 읽고 쓴다(`apps/docs/src/renderer/ai/translate-runs.ts`). 쓴 글은 기존 저장 경로(`textboxParasPatch`)로 나간다. 문서 엔진 패키지는 고치지 않았다. 도구 정의가 바뀌어 `ai-translation-profile` 테스트의 도구 목록 해시를 다시 고정했다.
- **범위.** 1단계는 docx만이다. xlsx와 AI 채팅의 OCR 팝업은 그대로다. 상자 안 글의 번역은 변경 추적(`revise_blocks`)과 이중 언어 쌍(`add_bilingual`)을 지원하지 않는다.

## 버린 대안

- **이 PC의 OCR 엔진(Vision, Windows.Media.Ocr)으로 박스를 얻기**: 결정 0102가 이미 배제했고, Linux와 도우미 없는 빌드에서 안 된다.
- **사람이 직접 박스를 긋기**: 그림이 많으면 번거롭다. 대신 AI가 제안한 박스를 사람이 고친다.
- **박스를 텍스트 상자 대신 다른 방식으로 놓기**: 번역은 되지만 "그림 위 박스" 모양이 사라진다.
- **번역 포함을 나중으로 미루기**: 요구사항에 어긋난다.

## 결과

- docx 그림에서 OCR하면 배치 화면에 "그림 위(글이 있는 곳마다 상자)"가 기본으로 뜨고, 박스가 없거나 상자를 놓을 수 없는 그림은 문단으로 간다.
- 실제 구독 AI가 준 좌표가 그림의 글과 맞는지, Word와 LibreOffice에서 상자가 보이는 모양은 아직 사람이 확인하지 못했다(`docs/tracking/findings.md`).
- 화면 문구 9개를 21개 언어로 더했고 19개 언어는 AI 초안이다.
