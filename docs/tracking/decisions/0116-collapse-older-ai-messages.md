# 0116 — 오래된 AI 대화는 펼쳐서 본다

- 날짜: 2026-11-18
- 상태: 적용

## 맥락

오래 연 문서의 AI 대화는 Markdown, 출처, 도구 내역을 모두 화면에 올려 두어 렌더러 메모리를 늘렸다. 대화를 지우거나 모델에 주는 내용을 줄이는 대신 화면에 올리는 양을 줄인다.

## 결정

아홉 편집기는 공용 `useChatWindow`로 최근 약 30개 항목만 그린다. 사용자 메시지와 이어지는 AI 답변을 자르지 않고, 진행 중인 답변도 숨기지 않으므로 한 차례가 길면 30개를 넘을 수 있다. 워드·엑셀·파워포인트의 과거 대화와 현재 대화도 합쳐 같은 한도를 적용한다.

위쪽의 ‘이전 메시지 N개 보기’를 누르면 전체를 펼친다. 다음 요청이 시작되거나 새 사용자 메시지가 더해지면 다시 접는다. 펼칠 때 기존 메시지의 스크롤 위치를 보존한다. 원래 항목 번호를 유지하여 되돌리기·다시 보내기·출처 이동은 같은 항목을 가리킨다.

대화 저장, 모델 맥락, 프로젝트 기록은 바꾸지 않는다. 펼침은 화면 상태뿐이다. 문구는 21개 언어로 제공한다.

## 확인

공용 시험이 차례 경계, 진행 중 메시지, 펼침·다음 요청의 접힘, 원래 번호와 저장 자료 보존을 확인한다. 엑셀 화면 시험은 접힌 메시지의 다시 보내기가 원래 번호를 받는지 확인한다.
