AI가 고친 곳을 채팅에서 바로 찾아갈 수 있습니다.

## 새로 들어간 것

- 채팅에서 변경 위치를 누르면 해당 문단, 셀 또는 슬라이드로 이동합니다.
- 파일 검색에서 64MiB가 넘는 Word, Excel, PowerPoint, ODT, EPUB, XMind 문서도 본문으로 찾을 수 있습니다.

## 고친 것

- 한글 문서에서 표 안의 표를 편집하고 저장할 때 여러 쪽에 걸친 표의 배치가 흐트러지는 문제를 고쳤습니다.
- Ctrl을 누르고 마우스 휠을 돌리면 문서 배율이 5%포인트씩 바뀝니다. Mac에서는 ⌘를 사용합니다.

## 설치

- Windows x64에서는 `tandem-office-Setup-0.15.10.exe`를 받아 실행합니다. Mac과 Linux는 기존 설치 파일을 계속 사용할 수 있습니다.
