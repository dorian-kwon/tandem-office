번역할 때 이탤릭을 자동으로 넣을 수 있고, 선택한 글을 웹 검색이나 구글 번역으로 바로 보낼 수 있습니다. 번역 창에서 AI에 반복해서 보내는 자료도 줄였습니다.

## 새로 들어간 것

- **이탤릭 자동 적용:** 프로젝트의 글쓰기 방식에 이탤릭 항목이 생겼습니다. 새 프로젝트는 자동 적용으로 시작하며, 기존 프로젝트는 상세 화면에서 켤 수 있습니다. 영어로 옮길 때 작품 제목, 외래어, 학명 등에 적용합니다. 단순 강조에는 넣지 않으며 한국어·중국어·일본어 번역에는 적용하지 않습니다. 감수에서는 이탤릭 규칙만을 이유로 맞는 번역을 고치지 않습니다.
- **웹 검색과 구글 번역:** 워드에서 글을 선택하면 “AI 요청” 옆에 두 버튼이 나타납니다. 누르면 브라우저에서 구글 검색이나 구글 번역이 열립니다. 구글 번역의 도착 언어는 번역 프로젝트의 목표 언어를 따릅니다. 선택한 글은 버튼을 누를 때 구글에 전송됩니다.
- **프로젝트용 새 폴더:** 프로젝트를 둘 장소를 고른 뒤 그 안에 새 폴더를 만들어 바로 사용할 수 있습니다.

## 고친 것

- **원문 서식 유지:** 번역 지침에 줄 바꿈, 탭, 목록 등 원문 서식을 유지하도록 명시했습니다. 이탤릭을 넣을 때도 같은 지침을 따릅니다.
- **번역 요청의 자료량 축소:** 번역 출력 창에서 쓰지 않는 도구와 지침을 빼 고정 입력량을 약 40% 줄였습니다. 후속 요청에서는 이전 작업에서 읽은 긴 문서 내용의 앞부분만 다시 보냅니다. 현재 작업에서 읽은 내용과 사용자의 지시는 유지하며, 필요한 내용은 다시 읽을 수 있습니다. 실제 응답 시간이 얼마나 줄었는지는 아직 측정하지 못했습니다.
- **최근 번역 문서 정리:** 폴더가 삭제됐거나 원본과 번역본이 모두 없어진 항목은 목록에서 자동으로 빠집니다. 외장 드라이브가 빠진 것처럼 일시적으로 폴더에 닿을 수 없는 경우에는 목록에 남깁니다.
- **폴더 변경 알림 오류:** 닫힌 탭의 화면에 폴더 변경 알림을 보내다 오류가 나도 다른 열린 화면에는 알림이 전달되도록 고쳤습니다.

## 알려진 한계

- 이탤릭을 넣을 낱말은 AI가 판단하므로 틀릴 수 있습니다. 저장된 `.docx`의 서식 속성과 다시 열기는 자동 검사했지만, Word 프로그램에서 직접 확인하지는 못했습니다.
- 표 안의 번역은 자동 저장 뒤 실행 취소·다시 실행과 재저장을 검사했습니다. 표의 모든 구조와 서식을 확인한 것은 아닙니다.
- 저장소가 비공개라서 업데이트는 `gh auth login`으로 저장소 접근 권한이 확인되는 PC에서만 받을 수 있습니다.

## 설치

- Windows: `tandem-office-Setup-0.14.2.exe`를 받아 실행합니다. 서명이 없어 “Windows의 PC 보호” 창이 뜨면 “추가 정보” → “실행”을 누릅니다.
- Mac과 Linux: 이번 버전에는 설치 파일이 없습니다. 이전 버전(0.14.0)을 계속 사용할 수 있습니다.
