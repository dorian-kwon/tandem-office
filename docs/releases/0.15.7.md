업데이트 창에서 최근 버전을 골라 설치할 수 있습니다.

## 새로 들어간 것

- 업데이트 버튼 오른쪽 화살표를 누르면 이 PC에 설치할 수 있는 최근 버전이 최대 5개 나옵니다. 지금 쓰는 버전에는 `Current`가 붙습니다.
- 버전을 고르고 설치 파일을 받은 뒤 **다시 시작 및 설치**를 누르면 선택한 버전으로 바뀝니다. 최신 버전을 쓰는 중이라면 **업데이트 확인…**에서 **다른 버전**을 열 수 있습니다.

## 설치

- Windows x64에서는 `tandem-office-Setup-0.15.7.exe`를 받아 실행합니다.
- Mac과 Linux는 기존 설치 파일을 계속 사용할 수 있습니다.
