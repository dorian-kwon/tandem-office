# Проекты перевода

Проект перевода собирает в одной папке документы, которые вы хотите перевести, справочные материалы и глоссарий и каждый раз даёт ИИ одни и те же инструкции. ИИ помогает переводить документы Word и другие, а текстовый PDF может перевести в новый PDF.

## Что входит в проект

- **Оригинал**: документы для перевода. Приложение хранит собственную копию в папке `source/` проекта; выбранный вами файл никогда не открывается и не изменяется.
- **Справочные материалы**: вспомогательные материалы, например прежние переводы или руководства по стилю.
- **Глоссарий**: термины, которые всегда нужно переводить одинаково.
- **Результат**: переводы, которые вы пишете, в папке `output/` проекта.

## Три экрана

1. **Список проектов**: откройте **Перевод** на боковой панели главной страницы. Здесь вы создаёте, открываете и удаляете проекты и пишете общий системный промпт, который действует для каждого проекта перевода.
2. **Сведения о проекте**: языки, промпт проекта (дополнительные инструкции только для этого проекта), списки документов для перевода, справочных материалов и глоссария, а также выбор способа чтения отсканированных страниц (OCR). Кнопка **Открыть перевод** у документа начинает работу.
3. **Окно перевода**: копия оригинала слева и ваш перевод справа, рядом. Панель оригинала доступна только для чтения. **Скрыть оригинал** и **Скрыть перевод** отдают всё окно другой панели, а панель возвращается на прежнее место.

## Глоссарий

- Добавьте файл `.csv`, `.xlsx` или `.txt` (в `.txt` столбцы разделяются табуляцией). Каждая строка — один термин.
- Столбцы: исходный термин, перевод и, по желанию, примечание. Первая строка пропускается, только если в ней названы первые два столбца (например, source и target или term и translation); любая другая первая строка читается как запись глоссария.
- Файлы в UTF-16 (например, «Текст в Юникоде» из Excel) распознаются. Остальные файлы читаются как UTF-8, а если это не корректный UTF-8, то как CP949, поэтому корейские файлы из старых программ отображаются правильно.
- До 200 записей отправляются целиком. Если записей больше 200, отправляются только те, чей исходный термин встречается в переводимом тексте.

## Справочные файлы

- Когда вы добавляете справочный файл, приложение преобразует его в текст (хранится в `references/.md/`; сам файл никогда не меняется) и индексирует его слова. Каждый запрос на перевод несёт части, лучше всего подходящие к переводимому тексту, до 6000 символов, вместе с названиями файлов. Если весь справочный текст не длиннее этого, он отправляется целиком.
- В сведениях о проекте у каждого справочного файла виден статус: **Преобразован в текст** (откройте через **Показать преобразованный текст**, только для чтения), **Нужно OCR** (скан или изображение: из него ничего не отправляется; добавьте его как документ для перевода, распознайте через OCR и добавьте полученный документ Word как справочный) или **Не удалось прочитать**.
- При необходимости ИИ может прочитать справочный файл с помощью инструментов проекта.

## Отсканированные PDF и изображения (OCR)

- В отсканированном PDF или изображении ещё нет текста для перевода, поэтому ИИ сначала читает его. В сведениях о проекте выберите, какой ИИ читает: **ИИ (Claude)**, **ИИ (ChatGPT)** или **Выключено**. Если выключено, сканы и изображения нельзя открыть для перевода.
- Страницы для чтения вы выбираете по одной или кнопкой **Выбрать все**. Читаются только выбранные страницы.
- Изображения страниц отправляются ИИ только после того, как вы подтвердите на экране проверки, где указано, сколько страниц будет отправлено и какой ИИ используется. Это может расходовать лимит вашего тарифа, а платное подключение перед отправкой помечается как платное.
- Прочитанный текст сохраняется как документ Word в папке результатов. Переведите этот документ в окне перевода с помощью панели ИИ.
- Поддерживаются изображения PNG и JPEG. Изображения GIF, BMP, TIFF и WebP, изображения больше 20 МБ и PDF с паролем не поддерживаются.

## Перевод PDF

- Текстовый PDF переводится в новый PDF в папке результатов. Можно также выбрать двуязычный PDF, где перевод стоит рядом с каждой исходной страницей.
- Экран проверки показывает число обращений к ИИ и используемый ИИ до отправки чего-либо. Перевод текстовых PDF использует общий для приложения **ИИ для работы** из Настроек, а OCR — ИИ, выбранный в проекте.
- Если перевод остановился, **Записать готовое** сохраняет переведённое. Когда вы снова откроете документ, нажмите **Продолжить**, чтобы отправить только оставшиеся блоки.

## Ограничения

- Изменения в панели оригинала сохранить нельзя. В некоторых редакторах можно вводить текст в памяти, но файл в `source/` не записывается.
- **Перевести заново** переводит всё с начала, но сохраняет блоки, которые вы сами исправили в двуязычном виде редактора PDF.
- Арабский, иврит и хинди нельзя выбрать языком перевода для переведённого PDF.
- Окно, оставленное открытым надолго, перестаёт действовать; откройте его снова из проекта.
