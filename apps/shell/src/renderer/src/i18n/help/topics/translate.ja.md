# 翻訳プロジェクト

翻訳プロジェクトは、翻訳したい文書、参考資料、用語集を1つのフォルダーにまとめ、AIに毎回同じ指示を伝えます。AIはWordなどの文書の翻訳を手伝い、テキストPDFは翻訳した新しいPDFにできます。

## プロジェクトに入るもの

- **原文**: 翻訳する文書です。アプリはプロジェクトの`source/`フォルダーに専用のコピーを置き、選んだ元のファイルは開いたり変更したりしません。
- **参考資料**: 過去の訳文やスタイルガイドなどの背景資料です。
- **用語集**: いつも同じ訳語にしたい用語です。
- **出力**: 自分で書く訳文で、プロジェクトの`output/`フォルダーに保存されます。

## 3つの画面

1. **プロジェクト一覧**: ホームのサイドバーで**翻訳**を開きます。ここでプロジェクトを作成、開く、削除でき、すべての翻訳プロジェクトに適用される全体のシステムプロンプトも書けます。
2. **プロジェクトの詳細**: 言語、プロジェクトプロンプト（このプロジェクトだけの追加の指示）、翻訳する文書・参考資料・用語集の一覧、スキャンしたページの読み取り方法（OCR）の選択があります。文書の**翻訳を開く**で作業が始まります。
3. **翻訳画面**: 左に原文のコピー、右に自分の訳文が並んで開きます。原文側は読み取り専用です。**原文を隠す**と**訳文を隠す**を押すと、もう一方がウィンドウ全体を使い、再表示すると元の位置のまま戻ります。

## 用語集

- `.csv`、`.xlsx`、`.txt`のファイルを追加します（`.txt`は列をタブで区切ります）。1行が1つの用語です。
- 列は、原語、訳語、必要なら備考の順です。1行目は、最初の2列が列名（たとえばsourceとtarget、termとtranslation）のときだけ読み飛ばされ、そうでなければ1行目も用語集の項目として読み込まれます。
- ファイルはUTF-8として読み込み、UTF-8でなければCP949として読み込みます。古いプログラムで作った韓国語のファイルも文字化けしません。
- 200件までは全件を送信します。200件を超えると、翻訳する文に原語が出てくる項目だけを送信します。

## 参考ファイル

- 翻訳を依頼するとき、参考ファイルは名前だけを送信し、内容は送信しません。
- AIは必要に応じて、プロジェクトのツールで参考ファイルを読むことができます。

## スキャンしたPDFと画像（OCR）

- スキャンしたPDFや画像にはまだ翻訳できる文字がないため、AIが先に読み取ります。プロジェクトの詳細で、読み取るAIを**AI（Claude）**、**AI（ChatGPT）**、**オフ**から選びます。オフにすると、スキャンと画像は翻訳のために開けません。
- 読み取るページは1ページずつ、または**すべて選択**で選びます。選んだページだけが読み取られます。
- ページの画像は、確認画面で確認してからAIに送信されます。確認画面には、送信するページ数と使用するAIが表示されます。ご利用のプランの利用枠を使うことがあり、料金がかかる接続は、送信前に有料と表示されます。
- 読み取ったテキストは出力フォルダーにWord文書として保存されます。その文書を翻訳画面でAIパネルを使って翻訳してください。
- PNGとJPEGの画像に対応しています。GIF、BMP、TIFF、WebPの画像、20 MBを超える画像、パスワード付きのPDFには対応していません。

## PDFの翻訳

- テキストPDFは、出力フォルダーに翻訳した新しいPDFとして作られます。原文の各ページの横に訳文を並べた対訳PDFも選べます。
- 確認画面で、AIの呼び出し回数と使用するAIを表示してから送信します。テキストPDFの翻訳は設定のアプリ全体の**使用するAI**を使い、OCRはプロジェクトで選んだAIを使います。
- 途中で止まったときは、**完了分を書き出す**で翻訳済みの部分を保存できます。文書をもう一度開いて**続ける**を押すと、残りのブロックだけを送信します。

## 制限

- 原文側での編集は保存できません。エディターによってはメモリ上で文字が入力できますが、`source/`のファイルは書き換わりません。
- **もう一度翻訳**は最初からすべて翻訳しますが、PDFエディターの対訳表示で自分で直したブロックはそのまま残します。
- アラビア語、ヘブライ語、ヒンディー語は、翻訳PDFの訳文の言語にできません。
- ウィンドウを長く開いたままにすると期限が切れます。プロジェクトからもう一度開いてください。
